# ETA-Motion

**Efficient Topology-Agnostic Motion Diffusion via Sparse Joint Learning**  
Seoyoung Hwang and Tae-Kyun Kim · WACV 2027

Project page source, including method figures and mesh animation results.

## Local preview

Requires Node.js.

```sh
npm run dev
```

Open http://localhost:4173.

## Updates

Edit the page in `site/` and publication links in `site/config.js`.

```sh
npm run check
```

GitHub Actions deploys `site/` to GitHub Pages on pushes to `main`.
